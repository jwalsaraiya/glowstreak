## 📊 Overview

Most habit trackers fail because they create friction with rigid workflows and bloated interfaces. 

**Glowstreak** is engineered for speed and visual clarity. By pairing **shadcn/ui** design tokens with **Recharts** interactive data telemetry, it transforms daily habits into glanceable momentum metrics.

---

## 🌟 Core Modules

| View | Purpose & Functionality |
| :--- | :--- |
| **📈 Analytics Engine** | Longitudinal completion rates, streak stability indices, and velocity curves rendered with interactive charts. |
| **📅 Habit Calendar** | Interactive calendar heatmap showcasing consistency streaks, missed days, and habit stacking history. |
| **🎯 Focus Dashboard** | High-priority daily checklist with instant keyboard toggle, progress rings, and streak counters. |
| **📝 Linked Notes** | Lightweight markdown notes system for journaling context, obstacles, and reflections tied to specific habits. |
| **🌗 Adaptive Theming** | System-synced dark tarmac and light mode with full keyboard navigation and accessible contrast. |

## 🛠️ Architecture

```
src/
├── components/          # Reusable UI primitives (dialogs, buttons, date pickers)
├── pages/
│   ├── Analytics.tsx    # Recharts data aggregation & trend curves
│   ├── Calendar.tsx     # Monthly/weekly heatmaps & event scheduling
│   ├── Dashboard.tsx    # Active streak cards & daily quick-actions
│   ├── Notes.tsx        # Reflection logs & habit context
│   └── Settings.tsx     # Theme toggles & notification preferences
├── hooks/               # Custom query and local persistence hooks
└── lib/                 # Tailwind utility merges and date calculations
```

## 🚀 Quickstart

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/jwalsaraiya/glowstreak.git

# 2. Navigate to project root
cd glowstreak

# 3. Install packages
npm install

# 4. Start local development server
npm run dev
```

Open `http://localhost:5173` to view the application.
